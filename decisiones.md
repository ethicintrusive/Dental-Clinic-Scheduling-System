Decisiones de desarrollo

Metodología de trabajo

Durante el desarrollo de este proyecto decidí adoptar una metodología distinta a la programación tradicional.

Mi objetivo no es que una IA escriba todo el código ni escribir cada línea manualmente sin apoyo. Busco un punto intermedio donde las decisiones importantes sean tomadas por mí y la implementación sea construida de manera colaborativa con la IA.

La IA cumple el rol de:

- Copiloto técnico.
- Co-arquitecto del sistema.
- Co-programador.
- Revisor técnico.

Mi rol consiste en:

- Comprender el problema de negocio.
- Diseñar la arquitectura.
- Definir los módulos del sistema.
- Elegir las tecnologías.
- Tomar las decisiones técnicas importantes.
- Validar cada implementación.
- Comprender completamente el código antes de aceptarlo.

Desarrollo conversacional

En lugar de escribir prompts extensos para obtener una solución completa, prefiero trabajar mediante conversaciones.

La metodología consiste en que la IA formule preguntas similares a las que realizaría un desarrollador senior durante una reunión de diseño.

Ejemplos:

- ¿Qué problema resuelve esta pantalla?
- ¿Qué datos necesita este formulario?
- ¿Qué responsabilidad tendrá esta función?
- ¿Dónde debería almacenarse esta información?
- ¿Conviene utilizar un objeto o un arreglo?
- ¿Esta lógica pertenece realmente a este módulo?

Una vez tomadas esas decisiones, la implementación del código resulta mucho más sencilla.

Filosofía

No considero que mi principal valor sea escribir grandes cantidades de código.

Mi principal aporte consiste en:

- Diseñar sistemas.
- Comprender procesos de negocio.
- Encontrar patrones.
- Detectar oportunidades de mejora.
- Iterar soluciones.
- Validar implementaciones.
- Coordinar herramientas para construir soluciones.

El código es una consecuencia de esas decisiones.

Objetivo

Mi objetivo profesional es convertirme en un profesional capaz de resolver problemas reales mediante aplicaciones web, utilizando la inteligencia artificial como acelerador del desarrollo, sin delegar el criterio técnico ni las decisiones de ingeniería.
