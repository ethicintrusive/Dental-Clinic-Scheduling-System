# Agenda de Turnos para Clínica Odontológica

## Problemas a solucionar

* Dificultades para administrar la agenda.
* Reservas realizadas por mensajes o en papel.
* Duplicación de turnos.
* Superposición de horarios.
* Pérdida de turnos.

## Herramientas de construcción

* HTML5
* CSS3
* JavaScript

## Objetivos de la aplicación

* Agendar turnos.
* Gestionar el estado de atención de cada paciente.
* Registrar los tratamientos realizados.

## Posibles mejoras futuras

* Chat automático para responder preguntas frecuentes desde la web.
* Seguimiento automático del paciente mediante mensajes impulsados por IA.

## Limitaciones

* El sistema será completamente manual.
* No contará con base de datos.

## Arquitectura

* Módulo de registro de pacientes.
* Módulo de control de estados.
* Módulo de agenda de turnos.
* Módulo de historial personalizado (según el dentista y el paciente).
