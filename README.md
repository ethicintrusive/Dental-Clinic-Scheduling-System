# Dental-Clinic-Scheduling-System
<------Problemas a solucionar-------> 
Dificultades para administrar la agenda. 
Reservas por mensajes o en papel.
-Duplicaciones de turnos. 
-Superposiciones de horario 
-Perdida de turnos
<------Herramientas de construcción-------->
HTML5 
CSS3 
JavaScript
<-------Objetivos de la app----->
agendar turnos manejar el estado de atencion sobre cada paciente registrar los tratamientos
<------Posibles mejoras futuras -------->
chat automatico de preguntas frecuentes en la web seguimiento vía mensaje automático impulsado por ia para el paciente. 
<-----Limitaciones------> 
Sera manual, no automático 
Sin base de datos

Modulo de registro de pacientes

Modulo de agenda de turno
